<h1 align="center">WokCloud SDK para Go</h1>

<p align="center">Projeto do cliente Go para integrar aplicações com a API da WokCloud.</p>

## Estado do projeto

O SDK está em preparação. Ainda não foram publicados código Go, `go.mod` ou versões instaláveis neste repositório. A versão mínima de Go, o caminho de instalação e os métodos disponíveis serão confirmados com a primeira implementação.

O cliente será documentado a partir dos endpoints, autenticação e limites efetivamente disponíveis na WokCloud. Os exemplos de instalação e utilização serão testados antes de serem apresentados como suportados.

A [documentação inicial](https://github.com/wokcloudofc/sdk-api-go/blob/54075bd0036e5d1c898e502911ee331bfe181e02/README.md) continua disponível no histórico, como referência do trabalho anterior.

## Participar

Lê o [guia de contribuição](CONTRIBUTING.md) antes de propor uma alteração. Usa os modelos de issues para comunicar um erro ou explicar uma melhoria. Os pedidos de alteração são revistos pela equipa através de pull requests.

A [verificação automática](.github/workflows/verificacao.yml) valida os ficheiros essenciais e as ligações internas da documentação. Os testes da biblioteca serão acrescentados juntamente com a implementação.
